# Communication Serveur et Client

Les scripts FiveM sont divisés en deux types de portées : Les scripts **Client** et les scripts **Serveur**. 
- *Client:* Tout ce qui s'exécute sur l'instance de jeu du joueur (Interface, monde 3D, touches clavier).
- *Serveur:* Logique globale pour tous les joueurs (accès Base de données, synchronisation, sécurité).

La communication entre ces scopes passe par les événements `TriggerServerEvent` et `TriggerClientEvent`.

## Depuis le Client vers le Serveur
```lua
-- Côté Client :
TriggerServerEvent("myScript:giveItem", "water", 1)

-- Côté Serveur :
RegisterNetEvent("myScript:giveItem", function(itemName, count)
    -- Vérification de sécurité : `source` représente l'ID du joueur ayant envoyé l'événement
    local playerId = source
    print("Le joueur " .. playerId .. " veut " .. count .. "x " .. itemName)
    -- Traitement sécurisé de l'inventaire côté serveur
end)
```

## Depuis le Serveur vers le Client
```lua
-- Côté Serveur :
local playerId = 1 -- Exemple de joueur ciblé
TriggerClientEvent("myScript:showNotification", playerId, "Bienvenue sur le serveur !")

-- Ou à tous les joueurs en même temps :
TriggerClientEvent("myScript:showNotification", -1, "Reboot imminent du serveur.")

-- Côté Client :
RegisterNetEvent("myScript:showNotification", function(message)
    -- Afficher la notification sur l'écran du joueur
    BeginTextCommandThefeedPost("STRING")
    AddTextComponentSubstringPlayerName(message)
    EndTextCommandThefeedPostTicker(false, false)
end)
```
**Important**: Vous pouvez combiner `RegisterNetEvent` et la fonction de callback dans le même appel, ce qui rend le code plus propre.
