# Threads et Optimisation sur FiveM

Les threads sont des boucles qui s'exécutent simultanément dans vos scripts. Dans FiveM, `CreateThread` est largement utilisé pour exécuter des vérifications continues ou des boucles sans bloquer le thread principal du jeu.

## Créer un Thread
```lua
CreateThread(function()
    while true do
        -- Votre logique ici
        Wait(0) -- Important pour éviter un crash
    end
end)
```

## Astuces d'Optimisation (0.00ms ms)
Avoir une boucle qui s'exécute à chaque frame (`Wait(0)`) continuellement peut augmenter l'utilisation des ressources du script (resmon).

Pour optimiser :
1. **Temps d'attente dynamique :** Augmentez le temps de `Wait` lorsque le joueur ne fait rien de pertinent.
```lua
CreateThread(function()
    while true do
        local waitTime = 1000 -- Par défaut à 1 seconde
        local playerPed = PlayerPedId()
        local coords = GetEntityCoords(playerPed)

        -- Position cible d'exemple
        local targetCoords = vector3(100.0, 100.0, 20.0)
        local distance = #(coords - targetCoords)

        if distance < 5.0 then
            waitTime = 0 -- Exécution à chaque frame quand on est proche
            -- DrawMarker, DisplayHelpText, etc.
        end

        Wait(waitTime)
    end
end)
```
2. **Utilisez des variables en dehors de la boucle :** Ne redéclarez pas des variables statiques dans une boucle `while true`.
3. **Évitez les natives lourds dans les boucles :** Les natives comme `GetPlayers()` doivent être évités dans des boucles rapides.
