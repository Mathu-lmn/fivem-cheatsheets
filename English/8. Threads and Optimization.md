# Threads and Optimization in FiveM

Threads are loops that run concurrently in your scripts. In FiveM, `CreateThread` is widely used to run continuous checks or loops without blocking the main game thread.

## Creating a Thread
```lua
CreateThread(function()
    while true do
        -- Your loop logic here
        Wait(0) -- Important to prevent crashing
    end
end)
```

## Optimization Tips (0.00ms ms)
Having a loop run every frame (`Wait(0)`) continuously can increase the script's resource usage (resmon). 

To optimize:
1. **Dynamic Waiting:** Increase the `Wait` time when the player is not doing anything relevant.
```lua
CreateThread(function()
    while true do
        local waitTime = 1000 -- Default to 1 second
        local playerPed = PlayerPedId()
        local coords = GetEntityCoords(playerPed)

        -- Example target location
        local targetCoords = vector3(100.0, 100.0, 20.0)
        local distance = #(coords - targetCoords)

        if distance < 5.0 then
            waitTime = 0 -- Run every frame when close
            -- DrawMarker, DisplayHelpText, etc.
        end

        Wait(waitTime)
    end
end)
```
2. **Use variables outside the loop:** Don't redeclare static variables inside a `while true` loop.
3. **Avoid heavy natives in loops:** Natives like `GetPlayers()` should be avoided inside rapid loops.
